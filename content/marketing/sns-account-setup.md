# SNSアカウント設計（X・Threads）

アカウントの作成と投稿は、運営者（もとね）本人が行います。以下は、そのまま貼れる素材です。

## 1. 名前・ID・アイコン
- **表示名**: `Motonator｜言葉の元ネタ解説`（候補: `Motonator（モトネーター）｜元ネタ解説`）
- **ユーザー名（@）の候補**（取得できたもの）: `@motonator_com` ／ `@motonator_jp` ／ `@motonator_info`
  - サイト名に合わせて、XとThreads（Instagramと連動）で、できるだけ同じ名前にそろえる。
- **アイコン**: サイトのアイコン画像（`public_html/wp-content/themes/motonator/img/icon-512.png`）。ロゴ入りで、サイトと同じオレンジ。
- **ヘッダー画像**（Xのみ）: サイトのOGP画像（`img/ogp-default.png`）、または橙色の背景にサイト名だけのシンプルな画像。

## 2. プロフィール文（コピペ用）
### X（160字以内）
```
流行りの言葉・ネットスラング・アニメやゲームの名言の「元ネタ」を、出典つきでやさしく解説するサイト Motonator の公式アカウント。運営：もとね（IT企業勤務、ゲーム・アニメ・マンガ好き）。AIも活用し、運営者が確認して公開。毎日更新。
```
### Threads（150字以内）
```
その言葉、どこから来たの？ 流行語・ネットスラング・名言の元ネタを、出典つきでやさしく解説。運営：もとね。AIも活用し、運営者が確認して公開しています。
```
- **リンク欄**: `https://motonator.com/?utm_source=x&utm_medium=social&utm_campaign=profile`（Threadsは `utm_source=threads`）

## 3. 固定ポスト（最初の1本・Xに固定）
```
はじめまして、Motonatorです。
「その言葉、どこから来たの？」を調べる「元ネタ」解説サイトです。
・出典を確かめて書いています
・短く、やさしい言葉で
・毎日、新しい元ネタを追加
気になる言葉があれば、ぜひ検索してみてください。
https://motonator.com/?utm_source=x&utm_medium=social&utm_campaign=pinned
#元ネタ #流行語 #ネットスラング
```

## 4. ハッシュタグ（1投稿に1〜2個まで）
- 共通: `#元ネタ` `#流行語` `#ネットスラング` `#Motonator`
- ジャンル別: `#アニメ` `#ゲーム` `#漫画`（作品名のタグは、その作品の記事のときだけ）
- 流行語大賞の時期: `#流行語大賞`（11月上旬のノミネート発表〜12月初旬の発表ごろ）

## 5. 運用ルール
- **頻度**: 1日1〜3投稿。公開した記事の紹介を1つ、過去記事の再紹介（クイズ・豆知識）を1つ。
- **リンク**: 本文の最後、または返信（リプライ）に置く。URLには必ず計測用パラメータを付ける（X: `?utm_source=x&utm_medium=social&utm_campaign=YYYYMMDD`、Threads: `utm_source=threads`）。GA4の「流入元」に、SNSごとに表示される。
- **載せないもの**: 作品のスクリーンショット、セリフの長い引用、実在の人物への揶揄、断定できない由来（記事にも書いていないこと）。
- **画像**: 記事のアイキャッチ（AI生成の抽象イラスト）をそのまま使ってよい。
- **返信・引用**: 質問や指摘には、確認してから返す。誤りの指摘は記事に反映し、お礼を添える。
- **予約投稿**: Xの予約投稿、Threadsの予約機能、Buffer無料プランなどが使える（追加費用なし）。
- 投稿文案は、毎日の実行で `content/marketing/YYYY-MM-DD.md` に自動で作られる（記事ごとに2案、UTM付きURLの書き方つき）。

## 6. 最初の1週間の例
| 日 | 内容 |
|---|---|
| 1 | 固定ポスト＋「元ネタ」って何？の自己紹介 |
| 2〜3 | 公開済みの話題記事（ビジュ／エッホエッホなど）の紹介 |
| 4 | クイズ形式（「40秒で支度しな」は何の作品のセリフ？） |
| 5 | 豆知識（ゆうべはおたのしみでしたね、条件は？） |
| 6〜7 | 新しい記事の紹介＋まとめ（今週の元ネタ3選） |
